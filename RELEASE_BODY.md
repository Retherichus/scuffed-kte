# Scuffed KTE: Lite and Standard

This release contains the two public editions of Scuffed KTE:

- `scuffed_kte.dll`: **Standard**, with the core tracker and additional accessibility and quality-of-life modules. Its optional Live Widget is disabled by default and can count nearby non-stealthed players even when occluded. See the README before enabling it.
- `scuffed_kte_lite.dll`: **Lite**, with the core combat-session tracker and history only.

Choose one DLL; do not install both. Close Guild Wars 2, place the selected file in the Nexus `addons` folder, then enable it through Nexus.

Once installed, you can switch between Lite and Standard from KTE's **Health** tab. Nexus applies the selected edition after a restart and retains your settings.

The tracker is anonymised and combat-gated. Gameplay systems are suspended in structured PvP. ArenaNet does not certify individual addons; third-party programs are used at the account holder's own risk. See the included README and ArenaNet's [third-party program policy](https://help.guildwars2.com/hc/en-us/articles/360013625034-Policy-Third-Party-Programs).

This is a binary-only release.
